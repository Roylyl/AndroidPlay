# AndroidPlay1.1.0验证记录

版本为1.1.0，内部构建号为41。以下记录用于区分源码实现、本地自动化检查与真机验证，不能替代Android和iPhone联调。

## 实现范围

- 已建立的CarPlay会话主动或被动断开时结束接收并关闭投屏Activity；连接前的高帧率回退保留。
- iAP2NowPlaying增量元数据合并，接收歌曲、专辑、歌手、播放状态、时长及进度；封面走独立文件传输通道，并防止旧曲目的迟到数据覆盖当前曲目。
- Android媒体会话和媒体通知同步，播放控制回传CarPlay；iPhone允许绝对进度跳转时启用系统拖动进度条。
- 已移除CarPlay主题设置及夜间模式同步，旧偏好不再控制外观。
- 输入/输出设备选择与热插拔监听，音乐/导航使用媒体音量，通话使用通话音量，Siri用途保留。

- 首页仅保留三个按钮；iPhone选择与连接设置移入CarPlay设置，自动读取失败直接弹窗手动输入。连接前Android16及以上尝试系统热点启动接口，失败/超时或旧版系统引导设置页，返回后继续连接。

- CarPlay设置、iPhone、帧率、声音、连接及音频设备选择改为应用内逐级页面；返回键先返回上一级。移除三指下滑手势，主页加入热点与Wi-Fi并行使用的稳定性提示。

## 尚需真机验证

1. 安装1.1.0后连接iPhone，主动断开及关闭iPhoneWi-Fi/蓝牙，确认关闭投屏并回到首页。
2. 播放音乐，查看通知栏与锁屏的歌名、封面和进度；切歌后确认不显示上一首封面。
3. 从系统媒体控件暂停、播放、切歌；在允许跳转的音乐App中拖动进度条，确认CarPlay与iPhone跟随。
4. 改变帧率时确认不启动/停止连接；选择120后验证本次120→90→60回退，并确认设置始终保留120，下次连接重新从120开始。
5. 播放音乐与导航、发起通话、使用Siri，分别检查系统音量通道与麦克风输入。
6. 在Android16及旧版设备检查热点启动请求、权限拒绝、超时、设置页返回与读取失败弹窗，确认已开启热点时正常连接。
7. 接入和拔出有线、USB及蓝牙音频设备，检查可见列表、实际播放和录音路由。

当前未接入独立歌词字段；QQ音乐等App通过标题上报的歌词按标题更新显示，不清空封面或播放进度。音乐App可能不提供封面、时长或进度跳转能力；系统控件布局及音频路由受Android版本、厂商和设备驱动影响。


## 首页样式与显示方向

- 首页和设置页共用圆角卡片背景、颜色与间距，首页改为适应横竖屏的纵向布局。
- AndroidPlay使用fullSensor；CarPlay默认sensorLandscape，设置选择竖屏时使用sensorPortrait，物理像素及毫米宽高同步换向，显示模式匹配不依赖方向。
- 本次独立APK构建成功；未操作Android真机或iPhone，竖屏布局与旋转行为尚未真机验证。


## 菜单过渡动画

- 首页和各级设置页使用统一220ms滑动与淡入淡出，进入与返回方向相反。
- 仅页面导航触发动画；状态刷新、设置值刷新和屏幕旋转不触发。系统关闭动画时直接切换，连续导航会清理旧过渡。
- 独立APK构建通过并更新桌面AndroidPlay-1.1.0.apk；未进行真机动画视觉验证。


## 设置入口与重新协商

- 移除连接设置页，权限检查和断开连接直接显示在CarPlay设置。
