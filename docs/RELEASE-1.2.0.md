# AndroidPlay1.2.0更新说明

本次更新加入四档应用语言，并统一主动、被动断开后返回首页的行为。

## 多语言

在“CarPlay设置→语言”中选择：

- 跟随系统
- 简体中文
- 繁體中文
- English

默认跟随Android系统，中文按简繁语言及地区匹配，其他系统语言显示English。语言设置覆盖首页、设置、连接提示、应用弹窗、权限说明和连接/媒体通知。

切换语言保留当前CarPlay会话，返回CarPlay等待页面时也会刷新应用提示。该设置不改变iPhone内部的CarPlay语言。

## 断开与返回首页

- 从应用或通知中主动断开，结束CarPlay会话并关闭投屏页面。
- iPhone结束会话或传输连接断开后，关闭CarPlay页面并恢复AndroidPlay首页。
- 返回首页时清空设置页面的导航历史，方便重新连接。
- 断开连接不会关闭Android系统热点。
- 保留原有高帧率启动回退和CarPlay内的系统返回键行为。

## 界面整理

- 返回箭头、列表箭头和选中标记改用矢量图形，与文字垂直居中对齐。
- 返回入口保留至少48dp点击区域，适配不同字号。
- 设置页避让屏幕挖孔；首页按钮按内容调整高度，避免大字号裁切。
- 自动检查使用开关，移除更新、日志操作的常驻解释文字，保留实际结果与错误。
- 版本号和构建号行不再响应无作用的点击。
- 避免重复的发行说明入口；关闭自动检查后不再产生新的自动更新提醒。

## 关于、更新与日志

进入“CarPlay设置”最后的“关于”页，查看应用版本与构建号，点击“检查更新”对比GitHub正式发行版，并打开新版APK或发行说明。

“自动检查更新”默认开启，应用启动或回到前台时每天检查一次。允许通知权限后会通过系统通知提醒新版；未授权时在应用内提示，同一版本确认后不重复提醒。手动检查不受每日频率限制，网络或GitHub访问失败时显示实际错误。通过浏览器下载APK后，由你确认安装，不自动安装。

点击“导出日志”，在系统文件选择器中指定保存位置，即可导出最近连接记录为TXT。日志会过滤网络密码、认证内容与常见设备标识，不导出认证文件或应用设置；不需要额外的存储权限。没有连接记录时会提示暂无日志。

## 安装包

- 文件名：`AndroidPlay-1.2.0.apk`
- 系统要求：Android9及以上
- 应用版本：1.2.0
- versionCode：45
- 包名：`com.androidplay.app`

无线连接继续使用Android本机系统热点和蓝牙。安装后按应用提示允许连接、麦克风及通知权限，再让iPhone加入热点并完成蓝牙配对。

项目与使用方法：[Roylyl/AndroidPlay](https://github.com/Roylyl/AndroidPlay)

## 连接修正（构建45）

- 排除移动数据、VPN和Wi-Fi客户端接口，等待可用热点接口后再发送连接参数。
- 检测到热点与无线局域网同时开启时，在屏幕底部短暂提醒连接可能不稳定；同一次同时开启期间只提醒一次。
- 提醒支持简体中文、繁體中文和English，不自动关闭热点或Wi-Fi。
